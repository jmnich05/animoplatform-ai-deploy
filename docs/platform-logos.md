# Platform logos

The "Platforms we work in every day" strip on `/` and `/web-commerce/` shows an official logo only where the brand's own rules allow this use (naming a platform we build in, on a services page). Every other platform is set as plain text in the same strip. Checked 2026-10-28.

## Shown as logos

| Platform | File | Source | Rule followed |
|---|---|---|---|
| WordPress | `assets/platforms/wordpress-logo-standard.png` (official BaseGray standard logotype, resized from 2000 px to 480 px wide; not otherwise altered) | https://wordpress.org/about/logos/ → https://s.w.org/style/images/about/WordPress-logotype-standard.png | WordPress Foundation trademark policy (https://wordpressfoundation.org/trademark-policy/): "it's OK to use the WordPress … logo as part of a page that describes your products or services," but not as part of our own branding. |
| Squarespace | `assets/platforms/squarespace-logo-horizontal-black.svg` (official file, unaltered) | https://www.squarespace.com/logo-guidelines → https://www.squarespace.com/s/squarespace-logos-m5gw.zip | Black or white version only, unaltered, with clear space, on white or a single solid background color, never on a low-contrast background or an image. The strip's background is solid cream. |

## Set as text, and why

| Platform | Why not a logo |

| Google Ads, Google Analytics, Google Search Console | Google logo use needs approval through Google's brand permissions process. |
| Klaviyo | No public logo kit or usage guidelines found on klaviyo.com. |
| Attentive | https://www.attentive.com/press has no logo kit; asks media to email press@attentive.com. |
| SimplePractice | https://www.simplepractice.com/press/ has no logo kit; asks to contact PR@simplepractice.com. |
| TherapyNotes | No press or brand page found. |

## Rules for anyone editing the strip

- Use only files downloaded from the brand's own brand or press page. Never use logo aggregator sites.
- Don't recolor, crop, stretch or add effects. Resizing is fine.
- Keep `alt` set to the brand name.
- Never describe Ánimo as a "partner" of a platform unless there is a signed partner agreement.
- Before adding a logo for a brand in the text table, re-check its rules and record the source and rule here.
